# Video script: Odoo Sales, quotation to invoice

Short animated intro from the Odoo Sales course, then a continuous live screen recording in an Odoo 20 database (fictional Northwind data): quotation for Harbour Hotels (25 reams), confirm, pick and deliver from Northwind Main, invoice INV/26-27/0009, payment. Server waits are trimmed. Narration: Microsoft neural voice Neerja (Indian English). Length 3:37.
